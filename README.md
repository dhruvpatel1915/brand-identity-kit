# Brand Identity Kit: Brew & Bloom Cafe

A complete brand identity design for a **fictional cafe and bakery**. This project shows how a logo, colors, fonts and print materials work together as one consistent brand.

![Primary logo](png/logo-primary.png)

## What is included
| Item | Files |
|---|---|
| Primary logo (light background) | `svg/logo-primary.svg`, `png/logo-primary.png` |
| Reversed logo (dark background) | `svg/logo-reversed.svg`, `png/logo-reversed.png` |
| Icon / app logo | `svg/logo-icon.svg`, `png/logo-icon.png` |
| Colour palette and fonts | `svg/color-palette.svg`, `png/color-palette.png` |
| Business card (front and back) | `svg/business-card-front.svg`, `svg/business-card-back.svg` |
| Letterhead (A4) | `svg/letterhead.svg`, `png/letterhead.png` |
| Social media profile picture | `svg/social-profile.svg`, `png/social-profile.png` |

## Design idea
The logo is a coffee cup with a green leaf rising from it like steam. It tells the brand story in one image: **Brew** (the cup) and **Bloom** (the leaf). The round shape works well as a social media profile picture and as a small icon.

## Colour palette
| Colour | Hex | Use |
|---|---|---|
| Espresso | `#3B2A20` | Main text, dark backgrounds |
| Cream | `#F6EFE6` | Main background |
| Terracotta | `#C8643C` | Main brand color, highlights |
| Sage | `#8FA58B` | Leaf and nature accents |
| Gold | `#D9A441` | Small accents on dark backgrounds |

## Fonts
- **Headings:** Playfair Display Bold (elegant, warm)
- **Body text:** Poppins Regular (clean, easy to read)

Both are free on Google Fonts. The SVG files list these fonts first and fall back to similar system fonts if they are not installed, so install them for the exact look.

## Design principles used
- **Consistency:** the same colors, icon and fonts on every item
- **Contrast:** dark and light versions of the logo for different backgrounds
- **Simplicity:** flat shapes that stay clear at small sizes
- **Whitespace:** space around the logo so it feels calm and premium

## Tools
Created as vector SVG artwork. The SVG files open in Illustrator, Figma, Inkscape and Canva, where you can edit colors and text.
